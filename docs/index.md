# Eksploracyjna analiza danych: zbiór Iris

Projekt przedstawia pełną EDA klasycznego zbioru Iris (150 obserwacji, 3 gatunki, 4 cechy morfologiczne). Sprawdzam rozkłady cech, zależności między nimi oraz to, jak dobrze cechy rozdzielają gatunki.

**Główne wnioski**:

- *Iris setosa* jest wyraźnie odseparowana od pozostałych gatunków, głównie przez wymiary płatka.
- *Iris versicolor* i *Iris virginica* częściowo się nakładają, więc potrzebują więcej niż jednej cechy.
- Długość i szerokość płatka są silnie skorelowane i mają największą moc dyskryminacyjną.

**Narzędzia:** Python, pandas, seaborn, matplotlib, Jupyter.
